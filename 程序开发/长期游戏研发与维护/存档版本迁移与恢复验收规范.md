# 存档版本迁移与恢复验收规范

> 目标：更新游戏时保留玩家进度。存档兼容是产品功能，不是发布后再补的技术细节。
> 本文细化已有 save-systems 与 save-integrity 技能，不替代它们。

## 一、存档数据契约

每份存档至少包含：
- schema_version：单调递增的整数；
- game_id：游戏身份，避免不同游戏或测试项目误读；
- save_id：存档槽位稳定 ID；
- revision：本槽位递增修订号；
- saved_at：诊断时间，不作为唯一排序依据；
- payload：实际游戏进度；
- checksum：可选的完整性校验，用于发现意外损坏，不是反作弊。

只保存可重建的权威数据：玩家进度、库存、任务标记、关卡状态、随机种子、稳定内容 ID 等。不要保存 Node/Component/场景对象引用、临时 UI 状态或可由权威数据重算的缓存。

存档格式应保持简单。单机小型游戏优先可读格式；只有文件规模或性能数据证明需要时才选择二进制格式。

## 二、版本迁移规则

1. 每次结构变更提升 schema_version。
2. 每个迁移只处理相邻版本：vN → vN+1。
3. 迁移函数只转换数据，不读写文件、不访问场景树、不播放动画、不发奖励、不依赖当前帧。
4. 迁移输入先深拷贝或解析为独立数据对象，绝不直接修改原始存档。
5. 迁移链按顺序执行，逐步检查输出结构；最终版本通过完整 schema 与内容 ID 校验后才允许进入游戏。
6. 新版本存档被旧客户端读取时，明确拒绝并保留文件；禁止猜测未知字段或用旧格式覆盖。
7. 旧迁移函数不得随意删除；至少保留所有仍可能存在于玩家设备上的正式发布版本迁移路径。
8. 缺少可选字段可补默认值；关键字段缺失、类型错误或无法映射时应中止迁移并保留原件。
9. 内容 ID 重命名/删除必须有显式映射或替代策略，不能靠显示名称或资源文件路径猜测。

## 三、安全写入与恢复

推荐写入顺序：
1. 生成完整新存档数据；
2. 序列化到临时文件；
3. 检查写入返回值、字节数和关闭结果；
4. 从临时文件重新读取并解析；
5. 校验 schema、checksum、必要字段和范围；
6. 保留上一份已验证存档作为备份；
7. 在同一存储卷内执行受控替换；
8. 再次读取正式文件，确认版本和 revision；
9. 成功后才清理超出保留数量的旧备份。

注意：不同平台文件系统的重命名、覆盖和断电语义不同。不能仅凭 API 名称宣称跨平台原子写入；必须在目标平台验证。任何失败都保留旧文件和恢复副本。

恢复顺序：
- 主存档有效：正常加载；
- 主存档损坏：提示恢复，优先选择最近一份通过校验的同类型备份；
- 备份也损坏：保留全部原文件并报告，不自动覆盖；
- 高版本存档：不作为损坏处理，不尝试降级写回；
- 调试/录制/作弊存档：不得自动替代自然进度存档。

## 四、测试必须覆盖的迁移路径

每个正式版本至少保留一份脱敏、可复现的旧存档样本。测试时复制样本，不在唯一原件上执行迁移。

必须验证：
- 每个受支持旧版本 → 当前版本；
- 最新版本 → 当前版本（无迁移路径）；
- 当前版本 → 当前版本（往返读写）；
- 更高版本 → 旧客户端（拒绝且原件不变）；
- 缺字段、空值、错误类型、越界数字、未知枚举；
- 未知/已删除内容 ID；
- 截断、空文件、错误编码、checksum 不匹配；
- 写入中断、磁盘空间不足、替换失败；
- 主存档损坏后的备份恢复；
- 多槽位互不污染；
- 调试槽位不能覆盖自然进度；
- 迁移失败后原始文件字节或逻辑内容保持不变。

## 五、版本发布与数据回滚

代码回滚与存档回滚是两个独立决策：
- 如果新版本已写入新 schema，旧代码可能无法读取；发布前必须确认回滚版本是否兼容。
- 如不兼容，必须有向前兼容的回滚读取器或经过验证的数据恢复路径。
- 不允许通过回滚代码自动把玩家数据降级并覆盖。
- 发布候选版本必须使用旧版本存档样本进行升级测试。
- 新版本首次写入前保留可恢复副本；新格式通过真实读取验证后才切换为主版本。

## 六、存档类别隔离

至少区分：
- story：自然游玩进度；
- lab：开发测试、传送、强制资源、调试数据；
- capture：录屏/复现固定状态；
- settings：设置数据，不含剧情进度。

调试或捕获状态不能自动写入 story。测试运行结束后验证 story 槽位没有被污染。

## 七、验收报告

每次存档变更记录：
- 游戏版本、构建、提交；
- 旧 schema → 新 schema；
- 测试样本来源与哈希；
- 每条迁移路径结果；
- 主存档、备份、恢复结果；
- 目标平台和文件系统；
- 失败样本、原始文件是否保持不变；
- 未覆盖旧版本与回滚限制。

未用真实旧版本样本验证时，只能标记“迁移逻辑单元测试通过”，不能标记“玩家存档兼容通过”。
