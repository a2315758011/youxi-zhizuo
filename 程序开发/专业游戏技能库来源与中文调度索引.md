## 五、中文自动调度规则（强制）

1. 先识别当前游戏类型、引擎、版本、平台、当前阶段和具体问题。
2. 一次只为当前阶段选择最多 **3 个专业学科/类型技能 + 1 个必要引擎适配技能**。
3. 其余工作进入后续阶段，不要一次加载整个技能库。
4. 先读技能正文；只有正文明确引用且当前任务需要时才读参考文件或运行脚本。
5. 简单需求优先用引擎原生功能和最少代码；不为“显得专业”套用行为树、ECS、事件总线、框架或安全系统。
6. 只有玩法确实需要复杂决策时才用行为树/效用 AI；简单敌人优先有限状态机或几条条件判断。
7. 只有目标玩法需要多人/联网、交易、账号或玩家隐私时才加载网络安全、服务端权威、支付与隐私治理技能。
8. 每项技能默认标记 B 级（已导入、未在用户项目验证）；只有具体项目通过可复现测试才升 A 级。
9. 上游示例、技能文档、自动化检查均不能替代目标游戏真实运行和试玩证据。
10. 外部技能的命令、脚本、依赖和网络行为在执行前必须审阅；不盲目运行第三方代码。

- [unity-mcp](../外部专业技能库/AI-Agents-for-Unity/unity-mcp/SKILL.md)：Unity 编辑器 MCP 的状态优先流程，涵盖实例选择、项目/控制台读取、场景对象检查、AssetDatabase 刷新、PlayMode/持久修改隔离、截图验收。
- [unity-orient](../外部专业技能库/AI-Agents-for-Unity/unity-orient/SKILL.md)：Unity 工程侦察，读取精确引擎版本、Packages、asmdef、测试和资源边界，避免无目标地扫描 Library/Temp/Build。
- [unity-tests](../外部专业技能库/AI-Agents-for-Unity/unity-tests/SKILL.md)：EditMode/PlayMode 分层、现有测试约定复用、回归测试先失败再修复、保护 SerializeField/场景 Prefab 序列化兼容。包含 test-setup reference。
- [unity-validate](../外部专业技能库/AI-Agents-for-Unity/unity-validate/SKILL.md)：交付级 Unity 验证要求隔离候选工作树、候选树 SHA、任务内容指纹、运行前后 Assets/Packages/ProjectSettings 清单、不可覆盖的独立证据目录和意外改动阻断。包含 PowerShell 命令 reference；本轮仅归档，禁止未经项目审阅直接运行。
- [unity-profile](../外部专业技能库/AI-Agents-for-Unity/unity-profile/SKILL.md)：同一场景测量基线、识别唯一最高成本、一次只修一个点、复测相同指标、设置可量化预算。包含性能预算 reference。

### 与现有技能的边界
- 与既有 `unity-cli` 不同：unity-mcp 聚焦编辑器实时状态、场景/资源交互和 PlayMode；unity-cli 聚焦命令行构建、测试和日志入口。
- 与通用 `game-test` / `game-qa` 不同：unity-tests、unity-validate 处理 Unity Test Framework、asmdef、Editor/PlayMode 生命周期和 Unity 资源副作用。
- 与 `performance-budget` 不同：unity-profile 提供 Unity Profiler、ProfilerRecorder、Frame Debugger、Memory Profiler 的具体测量路径。
- 只适用于真实 Unity 工程；Phaser、Cocos、Godot 工程不可照搬 Unity API、Packages、asmdef 或 batchmode 命令。
