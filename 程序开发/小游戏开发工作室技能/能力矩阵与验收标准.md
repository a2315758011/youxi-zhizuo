# 小游戏开发能力矩阵与验收标准

## 一、专业能力矩阵

| 能力域 | 工作内容 | 关键产物 | 验收重点 |
|---|---|---|---|
| 游戏策划 | 核心循环、规则、数值、难度、经济 | 玩法简报、规则规格、数据表 | 规则明确，可转为测试用例 |
| 程序开发 | 架构、输入、状态机、碰撞、AI、存档 | 可运行源码、接口契约 | 核心流程稳定，异常可恢复 |
| 游戏美术 | 角色、敌人、场景、道具、UI | 可编辑源资产、运行时资源 | 风格统一、语义正确、规格合格 |
| 动画特效 | 待机、移动、攻击、受击、死亡、技能 | 动作表、帧/骨骼源文件、预览 | 动作真实，身份和锚点连续 |
| 关卡地图 | 地形、障碍、路线、刷怪、波次 | 关卡数据、地图资源 | 可达、可玩、边界无漏洞 |
| UI交互 | 菜单、HUD、按钮、背包、触控 | UI规范、状态表、运行截图 | 控件可操作，无遮挡误触 |
| 音频 | 音乐、环境、攻击、命中、UI音效 | 音频事件表、源文件 | 触发正确、混音合理、许可明确 |
| 测试质量 | 单测、集成、冒烟、回归、设备测试 | 测试报告、日志、截图 | 关键路径真实执行 |
| 性能兼容 | 帧时间、内存、包体、加载、设备 | 性能预算、采样报告 | 目标设备与构建达标 |
| 架构治理 | 模块边界、数据契约、技术决策、技术债 | 架构图、决策记录、债务清单 | 依赖方向清楚，变更影响可追踪 |
| 存档兼容 | 存档版本、迁移、备份、冲突处理 | 存档 schema、迁移脚本、恢复演练 | 旧版本数据可安全读取或明确拒绝 |
| 版本发布 | 构建编号、版本说明、发布通道、回滚 | 发布记录、构建产物、回滚点 | 构建与测试证据绑定同一版本 |
| 线上维护 | 崩溃、错误、性能、故障分级与响应 | 诊断日志、故障记录、复盘 | 可定位、可止损、可恢复 |
| 内容生产 | 资产 ID、来源许可、导入、打包、更新 | 资产清单、内容版本、导入流水 | 无缺失引用、许可清楚、可回退 |
| 持续运营 | 玩家反馈、活动配置、版本节奏 | 迭代记录、活动配置、更新说明 | 不虚构指标，配置可审计可回滚 |

## 二、阶段门禁

- G0 范围锁定：目标、平台、玩法、预算、风险、能力和技术探针明确。
- G1 可玩原型：输入、核心玩法、反馈、胜利、失败、重开实际运行。
- G2 代表性体验：一段完整体验接入正式风格美术、UI、动画和必要音频。
- G3 内容集成：主要内容导入，资源引用正确，运行时可见，自动检查和抽检有效。
- G4 交付候选：目标平台构建、回归、性能、兼容、恢复和许可检查通过。
- G5 长期维护就绪：版本身份、存档迁移、崩溃诊断、性能基线、发布回滚和维护档案已建立。

门禁不通过，只退回受影响任务；不得用文档、代码存在或旧截图冒充通过。

## 三、核心测试清单

### 玩法
- 首次启动、开始、暂停、继续、胜利、失败、结算、重开。
- 快速连续输入、边界输入、非法操作、重复回调。
- 关卡切换、难度变化、资源耗尽、死局和极端数值。
- 存档、读档、损坏存档、旧版本数据迁移（适用时）。

### 美术与动画
- 资源可解码、尺寸正确、透明通道有效、边缘无污染。
- 角色轮廓、颜色、装备、朝向和锚点一致。
- 攻击须有真实出招；行走须有步态；受击/死亡有明确因果；建筑破坏有结构变化。
- 禁止仅整图平移、缩放、闪烁或渐隐冒充真实动作。
- 图集裁切、帧顺序、锚点、循环、事件时间和引擎播放均需验证。

### 交互与设备
- 按钮实际可用，文本可读，无重叠、遮挡和误触。
- 触摸、滑动、长按、横竖屏、安全区和系统返回符合设计。
- 后台/前台切换、断网恢复和音频恢复按适用性测试。
- 目标设备至少覆盖代表性低配/主流设备；无真机时明确标记未验证。

### 性能与发布
- 记录首屏加载、帧时间、峰值内存、资源加载/释放、包体大小。
- 以目标平台真实构建测量，不以编辑器预览代替。
- 微信和抖音分别构建、分别验收；Web PASS 不代表小游戏平台 PASS。
- 发布包、源码、资源清单、代码提交、资源版本和测试证据对应同一版本。
- 发布后保留上一稳定构建，验证升级路径、存档迁移与回滚方案。

## 四、结果状态

- VERIFIED：按规定方法实际通过，并有当前版本证据。
- FAILED：实际测试失败。
- BLOCKED：受权限、设备、工具或外部依赖阻塞。
- UNVERIFIED：尚未执行或证据不足。
- NOT_APPLICABLE：不适用，须说明理由。

## 五、交付清单

1. 完整源码与依赖锁定文件。
2. 可编辑美术源文件和正式运行时资源。
3. 角色、敌人、道具、场景、动画、音频资源清单。
4. 可运行构建版本及启动入口。
5. 测试报告、关键截图、日志和性能数据。
6. 代码提交、资源版本、引擎和平台工具版本。
7. 已知问题、未验证事项、恢复与回滚说明。
8. 许可与素材来源记录。
9. 长期项目的存档 schema、迁移策略、性能预算和线上诊断方案。

写完代码、生成素材或页面能打开，都不等于完整游戏交付。
