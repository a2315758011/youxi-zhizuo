# 小游戏开发软件工具链清单

本清单用于选型，不代表软件已安装或已通过验证。用户偏好免费工具，付费软件只作为可选项，不自动购买或订阅。

## 引擎与平台

| 软件/平台 | 用途 | 采用原则 |
|---|---|---|
| Cocos Creator 3.8 系列 | 2D/3D 游戏制作 | 微信/抖音小游戏优先评估；版本按项目与平台要求锁定 |
| 微信开发者工具 | 微信小游戏调试、预览、真机体验、上传 | 微信平台单独验收 |
| 抖音开发者工具 | 抖音小游戏调试、预览、发布 | 抖音平台单独验收 |
| Phaser | HTML5 2D 游戏框架 | 浏览器/H5/PWA 优先；小游戏平台兼容需实测 |
| Godot | 开源 2D/3D 引擎 | 独立游戏、桌面与移动端，按导出探针决定 |
| Unity | 商业 2D/3D 引擎 | 复杂 3D 或已有 Unity 工程；先核实许可与成本 |

## 测试与发布

- Cocos 编辑器预览：场景、资源引用、动画和脚本检查。
- 微信/抖音开发者工具：分别完成对应平台构建、预览和真机验收。
- Chrome/Edge：Web 运行、控制台、网络、帧时间和响应式检查。
- Android Studio/真机：安装、触摸、安全区、生命周期、性能和日志。
- GitHub Actions：仅在工作流实际配置并运行后，才能记录为已启用自动构建/测试。

## 默认组合

- 微信/抖音小游戏：Cocos Creator + 对应官方开发者工具 + GitHub Desktop + Krita/GIMP + Audacity。
- 浏览器/H5：Phaser + TypeScript + Vite + VS Code + Chrome/Edge DevTools。
- 独立游戏：按现有工程选择 Godot、Cocos 或 Unity，不因清单而迁移。

## 安装与版本治理

1. 安装前检查已有版本、项目要求、磁盘空间、许可和 SDK。
2. 优先复用现有软件，不覆盖项目锁定版本。
3. 版本记录在项目技术环境文档中。
4. 升级先在隔离分支/副本验证，不直接升级生产工程。
5. 费用、商用授权、素材许可和平台规则以执行当天官方条款为准。
6. 每个项目维护能力矩阵：软件/版本、可用状态、权限、最小探针、结果、限制和替代方案。
