# 2dimg2motion：2D 游戏动画生产技能

- 上游：[WU-HAOTIAN34/2dimg2motion](https://github.com/WU-HAOTIAN34/2dimg2motion)
- 固定上游 Git tree：`d4d73e243b6ff64b7cbb3879e45e951f972a7e62`（2026-11-02 检索）
- 上游最近推送：2026-07-02
- 许可证：MIT，原始 LICENSE 已保留。
- 收录技能：主流程 `2dimg2motion`、基准图标准化 `img2mo-std`、动作知识学习 `img2mo-learn`。
- 收录依赖：关键姿势重绘规范、动作提示词模式、透明画布标准化脚本、14 帧结构校验脚本、帧序列 GIF 预览脚本、英文/中文 README。
- 适用范围：2D 角色、植物、僵尸、道具和武器的 idle/walk/attack/hit/death 等动作序列；输出 RGBA 透明帧、关键帧、序列图和预览。
- 核心价值：先锁定角色身份、朝向、持有道具的屏幕侧、脚底基线与画布尺寸；生成关键姿势再生成中间帧；拒绝武器换手、肢体丢失、角色比例跳变等硬缺陷。
- 生成边界：姿势与动作图必须由图像生成模型重新绘制；本地脚本只允许标准化画布、透明背景处理、拆分/打包序列图、预览与校验，不能用仿射变换、复制粘贴肢体或程序插帧伪造动作。
- 脚本审阅：仅依赖 Python 标准库与 Pillow；未发现网络请求、shell 子进程或项目目录批量删除。标准化脚本的 `--check-only` 会创建并清理自己的临时文件/目录；正式输出会写入指定路径，不会覆盖输入图（默认输出另一个文件名）。
- 运行依赖：Pillow；执行前检查项目 Python 环境，不自动升级全局依赖。
- 重要适用限制：该技能面向逐帧 2D 动作生成，不等于恢复原版游戏已有的逐帧资源关系。对 PVZ 原始资源应先恢复原始帧序列/切片/锚点，再决定是否用该技能补充新动作，不能替换或扁平化原有动画。
- 评级：B（完整工作流与脚本已归档、静态安全审阅完成；未在真实游戏角色上生成并导入 Unity 验证）。
