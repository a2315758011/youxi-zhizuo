## 为什么不直接复制上游完整技能

上游部分生成后的技能包含：
- `~/.gstack` 私有目录读写；
- 会话与遥测日志；
- `gstack-game` 专属二进制工具；
- Claude Code 专用的交互函数与安装目录；
- 自动生成文件标记。

这些依赖并非当前游戏仓库的既有能力。直接复制会造成不可运行的技能、无必要的遥测和额外环境耦合。因此本仓库只保留 MIT 许可下的原始参考资料，并建立独立中文技能，去除上述依赖。

## 已保存的原始参考

- 难度曲线、经济模型、成长节奏；
- 玩家旅程阶段、玩家类型画像；
- 试玩分析、观察指标与访谈问题；
- 受控事件注入；
- 核心循环与玩家动机；
- 游戏手感反馈链、手感词汇、评估与常见误区。

## 采用时的证据边界

- 玩家画像模拟只能提出待验证假设，不是实际用户研究。
- AI 黑盒试玩只能发现可观察到的行为问题，不能替代真人玩家体验。
- 小样本试玩适合发现明显可用性问题，不足以证明留存、付费或版本差异具有统计显著性。
- 上游给出的具体数值阈值必须按游戏类型、遥测定义、目标玩家和样本量重新校准，不可作为普适定律。
- 上游参考中的心理学、样本量和市场判断不自动成为事实；需要时应独立查证原始研究。
