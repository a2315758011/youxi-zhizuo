# 游戏制作资料库

本仓库用于统一管理游戏制作规范、项目模板、技术方案和可公开的游戏工程。

## 目录
- `游戏策划/`：玩法、数值与需求文档
- `程序开发/`：工程规范与开发说明
- `美术与音效/`：素材规格、授权和制作流程
- `测试验收/`：测试清单和缺陷记录
- `项目模板/`：新游戏项目初始化模板

## 工作原则
1. 优先复用已有游戏工程，不重复造轮子。
2. 先确认引擎、版本、目标平台和真实工程状态，再修改。
3. 所有功能必须经过实际运行与测试，不能仅凭代码存在宣称完成。
4. 公共仓库禁止提交密钥、账号凭据、个人隐私、未经授权的商业素材和大型临时缓存。
5. 每次修改说明变更内容、测试证据、未完成事项及恢复方式。
