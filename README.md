# 游戏制作资料库

本仓库用于统一管理游戏制作规范、专业技能、长期研发方法论、项目模板、技术方案和可公开的游戏工程。

## 目录
- `游戏策划/`：玩法、数值与需求文档
- `程序开发/`：工程规范、开发说明、专业技能和长期维护体系
- `美术与音效/`：素材规格、授权和制作流程
- `测试验收/`：测试清单和缺陷记录
- `项目模板/`：新游戏项目初始化与长期维护模板
- `外部专业技能库/`：已筛选并保留许可证的第三方游戏开发技能原文

## 工作原则
1. 优先复用已有游戏工程，不重复造轮子。
2. 先确认引擎、版本、目标平台和真实工程状态，再修改。
3. 所有功能必须经过实际运行与测试，不能仅凭代码存在宣称完成。
4. 公共仓库禁止提交密钥、账号凭据、个人隐私、未经授权的商业素材和大型临时缓存。
5. 每次修改说明变更内容、测试证据、未完成事项及恢复方式。
6. 长期项目必须管理版本、存档兼容、性能预算、内容资产、发布回滚和线上故障。
7. 简单需求采用简单实现；任何额外架构、安全层、依赖和服务必须由真实需求或风险证明。
8. 技能只按当前阶段按需加载；每阶段最多 3 个专业技能加 1 个必要引擎技能，不把技能数量当成工作质量。
9. 本仓库只存放游戏制作内容，与 AIGC 漫剧资料库严格分离。
